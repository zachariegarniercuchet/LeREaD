What was built
src/extraction_baseline.py — rule-based extraction mirroring main_extraction.py's CLI (--split/--filename, --data-dir, --variant defaulting to original, --output-dir, --with-timestamp, --start/--end) and output layout (output/<split>_baseline_rules/<file>/<file>_final.html, so batch eval pairs them; single mode writes <file>.html flat so single eval pairs directly). No models, no gold input at runtime — pure regex + token-walk rules over data/original/test, emitting text-preserving <auto_label> tags with labelname/parent/id (+ empty docid/uri on parents for pipeline compat).
src/extraction_baseline_data.json — gazetteers mined only from train/dev gold (108 secondary titles, 148 authors, 33 bare surnames, 16 bare phrases, reporter/court/statute lists hardcoded from the same source). Test gold was used solely for measurement, never for rules.
Two-pass detection: (1) citation anchors, full decisions (X v. Y/X c. Y with token-walk boundary expansion), legislation (fragment-led + title-led), secondary sources (articles/books/dictionaries/Halsbury/Hansard/org-defs); (2) short forms licensed by pass 1 (harvested surnames/authors/acronyms, supra/Ibid./X case (supra), bare pinpoints labeled from the nearest parent).
