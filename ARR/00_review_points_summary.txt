4. REVIEWER b9UJ (Overall 2, Soundness 2) — most detailed
================================================================
Strengths noted: relevant task (preprocessing for retrieval), detailed hierarchical scheme + metadata, useful baselines + preliminary LLM-assisted study.
Weaknesses:
[B1] Very limited scale for a benchmark: 11 decisions, 5/3/3 train/dev/test. Even if span-rich, doc count limits reliability, representativeness, per-label analysis. Ask: justify why these 11, how representative of Canadian decisions.
[B2] Overstated extraction+disambiguation framing: experiments = extraction only; disambiguation = future; candidate pool too small for realistic retrieval. Ask: frame disambiguation modestly as released metadata / future work.
[B3] Workflow vs released gold not transparent: docs processed under mixed conditions (human-only, LLM-assisted verification, double annotation, pilot). Unclear which process produced final gold per doc. D10 in both extraction-only and verification settings -> ordering / familiarity / comparability questions.
[B4] Productivity analysis under-controlled: 29% gain on few timed docs; speed confounded by difficulty, fatigue, order, tool familiarity, environment. Ask: how timing recorded; were extraction vs verification controlled / counterbalanced.
Comments/suggestions:
[B5] Prompt design: copy-and-annotate format, chunking, few-shot given, but design/revision/validation process missing; results depend on prompt quality.
[B6] Motivation vs prior work: paper criticises prior sets as monolingual / too small, but v1 is also English-only + 11 docs.
[B7] Anchoring-bias interpretation too strong: verified-vs-LLM > raw-LLM-vs-gold is suggestive, not conclusive; could be easy references, shared guidelines, editing mechanics.
Author rebuttal already sent (13 Jul, rev. 14 Jul): span counts (4,062 mentions, 7,861 sublabels, 250k tokens); stratified sampling (court level, jurisdiction, period; App. B; CanLII; avoid tribunal/decade over-representation); per-label only App. Table 9, can remove; v2 >2x; disambiguation metadata in v1, eval in v2 (preliminary runs done); final v1 release = 11 docs human-only (extraction + disambiguation); experiment docs also released (4 extraction-only + 4 verification); D10 = Annotator 1 from-scratch (extraction-only, final test version = Annotator 1 complete) vs Annotator 2 verification of LLM output (separate purpose); RQ1 = 4 scratch (33k) vs 2 verification (59k); RQ2/RQ3 = 4 double-annotated, 2,714 spans, 85.5k tokens; 6 docs re-annotated (~39h); end-of-process, same annotators/platform/guidelines/order/task; identical task (mentions + sublabels); timer with inactivity stop, no latency/fallback; difficulty not controlled (acknowledged limit); will publish full prompts + details; motivation = scope (primary vs legislation + secondary unified), English now but French versions exist in source pool (future bilingual); anchoring will be softened to "consistent with", incl. alternative explanations + platform editing affordance.
